# Как запускать
``` shell
python -m venv venv 
source /venv/bin/activate (For Linux)
```
```shell
venv\Scripts\activate.bat (For cmd)
```
```cmd
.\venv\Scripts\Activate.ps1 (For PowerShell)
```
``` shell
pip install -r requirements.txt
```
## Запуск консольной версии
```shell
python main.py 
```
## Запуск веб приложения
``` shell
python ui/app.py 
```
