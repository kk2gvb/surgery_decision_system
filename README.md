# Как запускать
``` shell
python -m venv venv
```
For Linux
```shell
source /venv/bin/activate 
```
For cmd
```shell
venv\Scripts\activate.bat 
```
For PowerShell
```cmd
.\venv\Scripts\Activate.ps1 
```
``` shell
pip install -r requirements.txt
```
## Запуск консольной версии
```shell
python main.py 
```
## Запуск веб приложения
``` shell
python ui/app.py 
```
